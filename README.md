# Goldingen

MU Immortal sarı (golden) boss avı için Android otomasyon uygulaması.

- Haritada canlı sarı kafatası + yeşil oyuncu imleci okunur, yarıçap içindeki en yakın boss'a gidilir.
- Yarıçapta boss yoksa haritadaki Random düğmesine basılır.
- Boss ölümü sağ üstteki mini haritadan (kafatası soluklaşınca) anlaşılır.
- ATK/DEF (sol üst) okunur; ikisi de minimumun altındaysa buff noktasına gidilir.
- Ölüm ekranında Free Revival'a basılır.

APK: GitHub Actions her push'ta derler, Releases sayfasından indirilir.
